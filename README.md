#  Calculadora de Promedio de Notas

Aplicación web simple para calcular el promedio de notas y mostrar si el estudiante está aprobado o reprobado.

##  ¿Qué hace?

- Permite ingresar varias notas separadas por coma.
- Calcula el promedio automáticamente.
- Indica si está aprobado o reprobado.
- Muestra mensajes de error si los datos son inválidos.

##  Cómo usarla

1. Ingresar notas separadas por coma.
2. Presionar "Calcular promedio".
3. Ver el resultado en pantalla.

##  Cómo ejecutarla

Solo abrir el archivo `index.html` en el navegador.

##  Tecnologías usadas

- HTML5
- CSS3
- JavaScript
